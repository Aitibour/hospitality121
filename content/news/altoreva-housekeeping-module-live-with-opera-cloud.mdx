Altoreva says its Housekeeping module and two-way Oracle OPERA Cloud integration are live. In a submitted announcement published on November 17, the company said the connection was running at Eagle Aruba Resort. These are supplier-reported deployment details.

The announcement describes one platform for operations, security and housekeeping. According to Altoreva, the OPERA Cloud connection reads arrivals, in-room guest details, VIP levels, room status and room moves. It writes room status back to the property management system. The supplier also describes a housekeeping room board, attendant assignments, cleaning checklists and supervisor inspections.

## Checks for hotel operators

Hospitality121 analysis: Hotel teams evaluating the connection should map the room-status workflow before a pilot. Which system controls a status change, who can override it, and how does reception see that a room is ready?

Operators should ask the supplier to demonstrate conflicting updates, a room move during cleaning and a lost network connection. The pilot should include both housekeeping supervisors and front-desk staff, with an agreed process for resolving discrepancies.

Guest-data access deserves its own review. Teams should establish which roles can see each field, what audit records are retained and how access is removed when staff leave. They should also confirm supported PMS configurations, setup responsibilities and support arrangements before expanding a deployment.
